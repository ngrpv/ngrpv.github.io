# Следующий!

Браузерная игра про окно №7 в МФЦ: двенадцать смен, регламент меняется каждое утро. Статичная: сборки нет, зависимостей нет, работает без сети.

## Запуск

Открыть `index.html` в браузере или поднять любой статичный сервер в этой папке:

    python -m http.server 8000

Адрес на GitHub Pages: `https://ngrpv.github.io/okno7/` (Settings → Pages → Deploy from a branch → `main` / `(root)`).

## Что есть в игре

- Три роли и три сложности (Новичок / Обычная / Строгая). Сложность меняет число бесплатных ошибок, штраф, долю подделок, план и подозрительность ОБЭП.
- **Смена дня**: у всех игроков в один календарный день одинаковые правила, события, сюжеты и посетители. Результат можно переслать.
- **Знаки отличия** и **разбор прохождения** (точность, лучшая серия, что чаще упускали).
- Честный заработок: премия за день без ошибок и за первую неделю с чистым протоколом.
- Клавиши на компьютере: Пробел — следующий / вернуть, ← → и 1–9 — документы, S — сверка, B — регламент, T — телефон, Y и N — штампы, H — справка, M — звук. Справка есть и в игре.

## Структура

- `index.html` — разметка экранов, подключение скриптов, мета-теги для iOS и превью ссылок
- `css/style.css`, `css/fonts.css` — стили и подключение шрифтов; `fonts/` — woff2 (кириллица и латиница, лицензия SIL OFL, источник Google Fonts)
- `js/` — игра. Это обычные скрипты, они делят одну глобальную область, **порядок подключения в `index.html` важен**:
  `util` → `sound` → `graphics` → `data-*` (people, rules, days, season) → `state` → `arcs` → `arc-razan` → `visitors` → `docs` → `screens` → `shift` → `inspect` → `lens` → `decision` → `evening` → `achievements` → `help` → `daily` → `endings` → `keys` → `main`
- `balance-sim.js` — автопрогон кампании разными стратегиями без интерфейса: `node balance-sim.js 200 [easy|normal|hard]`
- `tests/run.js` — проверки без зависимостей: `node tests/run.js` (на GitHub запускается при каждом пуше, см. `.github/workflows/`)
- `tools/` — загрузчик игры для Node и исходники картинок для превью (см. `tools/README.md`)

Прогресс, знаки отличия, выбранная сложность и результат «Смены дня» хранятся в `localStorage` под префиксом `okno7.`.

## Почему не ES-модули

Состояние игры (`S`, `G`, `W`, `E`) — переменные, которые переназначаются из многих файлов. В модулях для этого пришлось бы заводить объект состояния и менять почти каждую строку. Пока это не окупается, поэтому файлы остаются обычными скриптами. От поломки порядка подключения защищает `tests/run.js`: он загружает скрипты в том же порядке и проверяет, что все файлы подключены.
