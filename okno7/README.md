# Следующий!

Сатирическая браузерная игра про работу окна №7 в МФЦ. Проверяйте документы, сверяйте их с регламентом и принимайте решения. Каждая смена приносит новые требования, а вечером нужно свести личный бюджет. Кампания длится 12 игровых дней. Есть три роли, три сложности, знаки отличия и разбор прохождения.

Игра работает на HTML, CSS и JavaScript. Сборка и установка зависимостей для запуска не нужны.

## Как запустить

Откройте `index.html` в браузере. Для локальной разработки удобнее запустить сервер из папки проекта:

```sh
python -m http.server 8000
```

Затем откройте [localhost:8000](http://localhost:8000).

Для публикации на GitHub Pages выберите ветку и корневую папку проекта в Settings → Pages.

## Как играть

1. Прочитайте распоряжение перед сменой: регламент меняется по ходу кампании.
2. Пригласите посетителя и изучите его документы. Вкладки переключают бумаги на столе.
3. Включите «Сверку» и выберите два поля либо поле и соответствующий пункт регламента.
4. Задайте вопрос, если нужно объяснение или документ можно исправить на месте.
5. Поставьте печать принятия или отказа. Для отказа выберите действующее основание.
6. Верните документы посетителю и переходите к следующему.

Следите за планом, жалобами и отношением начальства. Последствия решений отражаются в вечерних итогах и конце кампании.

## Воспроизводимые партии

Добавьте к адресу параметр `seed`, например `?seed=1042`. Можно использовать число или строку. При одинаковых действиях сид воспроизводит начальные условия и последовательность случайных событий. Декоративные эффекты могут отличаться.

Параметр применяется при начале новой игры. Кнопка «Продолжить» загружает прежнюю партию. Состояние генератора сохраняется вместе с прогрессом и восстанавливается при повторе дня.

После изменений генератора тот же сид может давать другую партию.

## Смена дня и управление

«Смена дня» предлагает одинаковую партию всем игрокам в одну календарную дату. Параметры URL в этом режиме не применяются.

На компьютере доступны клавиши: Пробел — следующий посетитель или возврат документов, ← → и 1–9 — вкладки, S — сверка, B — регламент, T — телефон, Y и N — печати, H — справка, M — звук.

Во время печати реплики нажмите на неё, чтобы сразу показать весь текст. Длинную реплику можно прокрутить.

## Сохранения

Прогресс автоматически сохраняется перед началом смены. Локальное сохранение хранится в браузере под префиксом `okno7.`. В окружении с подключённым хранилищем игра также синхронизирует прогресс с ним.

## Устройство проекта

- `index.html` — экраны и порядок подключения скриптов.
- `css/` — стили интерфейса и подключения шрифтов.
- `fonts/` — локальные шрифты и их лицензии.
- `js/` — данные, состояние партии, сюжетные модули и игровая логика.
- `tests/` — автоматические проверки.
- `balance-sim.js` — прогон кампаний разными стратегиями без интерфейса.

Скрипты используют общую область видимости. При добавлении модулей сохраняйте порядок подключений в `index.html`.

## Проверки

Для автоматических проверок нужен Node.js:

```sh
node tests/run.js
node --test
```

Для прогона баланса:

```sh
node balance-sim.js 20 normal
```

Число задаёт количество кампаний для каждой комбинации роли и стратегии.
